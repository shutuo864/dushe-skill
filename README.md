# 毒舌熨心 · 情绪也需要被接住

> 损友式每日心情熨烫助手。先怼一句，再帮你把情绪熨平。
>
> 不是心理咨询，也不是正能量鸡汤 —— 是一个会跟你说「你这不叫扛，叫硬撑」的搭子。

<br>

## 它做什么

每天你把当天的心情讲给它听（可以带一张日历图），它按固定结构回你六块：

| 板块 | 内容 |
|:--|:--|
| 📅 日历菜单 | 把今天变成一道菜：主菜是正事，配菜是心态，调料是那句自嘲 |
| 🔥 毒舌安慰 | 四步熨烫法：锚定 → 追问 → 积蓄（重负面时另有分级回应） |
| 📱 朋友圈文案 | 文艺 / 硬核 / 幽默 / 工程 四风格一次全出，附一键复制卡片 |
| 🦉 日历彩蛋 | 有日历图时，读图上的画与引文，落一句当天的解读 |
| 🏮 今日金句 | 从楹联库按心境匹配，配一张金句卡（本地 Pillow 渲染，可选 AI 生图底图） |
| 🗂️ 心情速览卡 | 1360×860 PNG，一天的心情浓缩成一张卡 |

再加上周期复盘：周日周报 / 月初月报 / 年初年报，把零散的日子连成一条心路曲线。

<br>

## 五段连通管道（v2.10.0+）

毒舌熨心不只是「接住情绪」，它还是整条成长链的**情绪数据源**。心情记录之后，可以顺着五段链式管道一路往下走——每段可单独触发，也可串跑（上一段输出即下一段输入）：

| 段 | 技能 | 做什么 | 触发语 |
|:--|:--|:--|:--|
| 一 | 拆解大师 | 拆事情结构（解决问题五步法） | 拆一下 |
| 二 | 破壁 | 拆自己的思维预设（八步流程） | 破壁一下 |
| 三 | 发芽师 | 跨域联想，长出 3-5 个新认知 + 发展方向 | 发芽一下 |
| 四 | 拷问官 | 逻辑审查，挑刺筛掉不扎实的方向 | 拷问一下 |
| 五 | 个人决策 Agent | 决策台账与复盘（目标函数 / 硬约束 / 复盘点） | 这事该不该做 |

一句话串跑：**「把最近的心情从拆解到决策跑一遍」**。

**下游可用性**：管道一 / 二 / 五的技能已上架 SkillHub，未装时会给出精确安装命令（需带原作者 namespace `user_429c9fdc`）；管道三 / 四所属的「李工大脑」尚未上架，此时毒舌熨心会**内置简版发芽 / 拷问降级**并如实标注，不装也能跑通全程。详见 `SKILL.md`「联动接口」节。

## 快速开始

### 方式一：WorkBuddy 技能目录

```bash
git clone https://github.com/shutuo864/dushe-skill.git
mkdir -p ~/.workbuddy/skills/dushe
cp -r dushe-skill/. ~/.workbuddy/skills/dushe/
```

然后在对话里输入：

```
@skill:dushe 今天加班到十点，方案又被推翻一次，有点顶不住。
```

### 方式二：SkillHub

在 SkillHub 搜索「毒舌熨心」安装（命令：`skillhub install dushe --namespace user_429c9fdc`）。

五段管道的下游技能（可选，按需安装）：

```bash
skillhub install chajjie-dashi --namespace user_429c9fdc   # 拆解大师
skillhub install pobi --namespace user_429c9fdc            # 破壁
skillhub install siwei-gongjuku --namespace user_429c9fdc  # 个人决策 Agent
```

## 依赖

- Python 3.8+
- `pillow`（卡片渲染，必需）
- `requests`（仅 Agnes 生图链路需要）

```bash
pip install pillow requests
```

缺少 Pillow 时自动退化为纯文字版，不报错。

## 可选配置

技能**零配置即可完整使用**。以下均为可选增强，未配置自动跳过：

| 能力 | 环境变量 / 配置 | 说明 |
|:--|:--|:--|
| AI 生图金句卡 | `AGNES_API_KEY` | 或本机配置里的 Agnes 凭据。不配则用本地 Pillow 金句卡 |
| 心情记录云同步 | `IMA_CLIENT_ID` + `IMA_CREDENTIAL` | ima OpenAPI 笔记接口。不配则记录只存本地 |

> 生图链路只出**零文字底图**，中文由 Pillow 本地叠真字 —— 避免模型画中文伪字。

## 关于隐私

这个技能会接触很私人的东西，所以边界写清楚：

- **心情记录只存本地**（`data/` 目录），不上传任何服务器；接 ima 是你自己配的通道。
- **本仓库不含任何真实个人数据**：`data/` 未纳入版本管理；弹药库为示例化脱敏版（原有的个人私密条目已替换为中性示例）；示例中的笔记 ID 均为占位符。
- **弹药库归你私有**：安装后 `references/flip-arsenal.md` 从空库开始，随你自己的对话逐步沉淀。
- 卸载 = 删目录，没有远端残留。
