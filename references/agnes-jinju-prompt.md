## 1. 三条硬规则

| # | 规则 | 判据 |
|:-:|:-----|:-----|
| 1 | **每日必出、同步生成** | 板块五与板块一~四在同一次执行内完成，不需要用户再说「生出金句卡」；有日历图片也出（不依赖「无图触发」） |
| 2 | **提示词逐日重拼** | 下方 6 个槽位全部由当天字段填。**必变项**：`金句物象`（随主金句）、`触发细节`（随当天事件）每天都必须变；**条件项**：心情变 → hex 必变、心路标签变 → 场景器物必变。⛔不再无条件要求「场景/物象/hex 三处全变」——连续两天同心情时 hex 与场景本就该与 `card_common` 同源，强改等于造假 |
| 3 | **一次底图，不二次扣费** | 每天只调一次 Agnes；底图不合格（文字区 σ 超标、落款压浅色）只做**本地重绘**（加强底部渐隐 / 收窄文字落区），不重复生图 |

## 2. 六个动态槽位（缺一即视为套模板）

| 槽位 | 取自 | 落到提示词哪一段 | ⛔ 禁止 |
|:----|:-----|:-----------------|:--------|
| ① 情绪等级 🟢🟡🟠🔴 | 执行流程第 2 步「判定情绪」 | 色调 hex 区间 + 时段/光线 + 整幅亮度 L 区间 | 写死「深棕暖调」或沿用昨天色值 |
| ② 心路标签 | 执行流程第 3 步 | 场景器物族（桌/窗/杯/书/山/椅…） | 每天都是同一张旧木书桌 |
| ③ 触发事件 / 心情自述 | 用户当次原文 | 一个具象细节（如「长途后的暮色」「会场没散的灯」） | 把事件文字、公司名、人名照排进画面；出现人物 |
| ④ 主金句 | 板块五所选楹联 / 日历引文（须过铁律-003 核验） | **主体物象**：把金句核心意象实物化 | 把金句文字放进画面（零字符铁律） |
| ⑤ 副文案（心境解读） | 板块五 | **构图**：留白比例 + 主体位置 + 情绪落点 | 主体居中顶满、金句区被遮挡 |
| ⑥ 出处 / 日期 / 节气 / 日历引文信息 | 板块一、板块五 | **只进本地叠字**，不进提示词画面 | 把出处写成画面题字、印章、书封小字 |

> ④ 是「结合金句内容」的硬落点：不是把金句写进 prompt 让 AI 画字，而是**把金句讲的东西变成一个可以拍出来的实物**。

|:---:|:----:|:--------------------------------|:-----------|:-----|:----:|
| 🟢 正面 | 青瓷 | `#DCE9E3 ~ #F3F8F6` | 清晨、晴光斜射 | 舒展、干净 | 深字 |
| 🟡 轻度负面 | 宣纸 | `#F5E6D3 ~ #FFF8EC` | 午后、薄云漫射 | 平缓、不使劲 | 深字 |
| 🟠 重度负面 | 秋檀 | `#221813 ~ #3B2A20` | 秋日傍晚、柔和侧逆光 | 沉静克制 | **浅字** |
| 🔴 崩溃级 | 朱笺 | `#F8DED5 ~ #FFF5F1` | 夜灯柔光（**不压抑、不暗黑**） | 先接住、留出气口 | 深字 |

- 高光/纸页/陶器色取该配色的 `tag` / `source` 字段（如秋檀 `#B1997C ~ #D2BFA4`），占 10%~25%；主色占 55%~75%；点缀色占 1%~5%。
- 深色底：整幅平均亮度 `L∈[18%,38%]`，叠字区 `L∈[20%,35%]`；浅色底：整幅 `L∈[72%,92%]`，叠字区 `L∈[78%,92%]`。
- **叠字区局部明暗波动 σ≤8%**，保证后期叠字对比度 **≥4.5:1**（铁律-027② 可执行判据）。

## 6. 副文案 → 构图（⑤）

| 副文案语气 | 主体位置 | 上方叠字区 |
|:-----------|:---------|:-----------|
| 收束词占优（别 / 不 / 慢 / 停 / 先 / 今晚 / 算了 / 莫 / 勿） | 严格位于**下三分之一、偏右** | 上方 ≥1/3 平整柔和、不放任何物件 |

> 两类词常同时出现（如「先放下，继续往前走一步」）：**按命中数多者判，平手偏向行动**（`scripts/agnes_jinju.py` 的 `pick_composition` 为准），避免只因一个「先」字就把整幅压成收束构图。

## 7. 提示词模板（固定骨架 + 当天槽位；`{}` 为必填变量）

```markdown
---
size: 960x1280
---
设计一张竖版 3:4 的真实摄影质感日签底图，{时段与光线}，{配色名}调，供后期叠加中文金句使用。这张图本身必须完全没有任何文字。

【画面内容·逐元素定义】
- 场景：{心路标签器物族} + {触发事件转成的具象细节}；{氛围词}。
- 主体（{副文案决定的位置}）：{金句物象}。{物象数量/状态限定}。
- 桌面/环境另有一件{器物族配角}；所有纸面、封面、杯身完全空白。
- 上方三分之一：平整柔和的{主色描述}虚化面，作为后期叠字区，不放任何物件、不放高对比纹理。
- 底部：留白，无杂物。

【颜色·可执行判据（hex）】
- 主色调限定在 {bg_bottom} ~ {bg_top}，占画面面积 55%~75%。
- 高光与器物限定在 {source} ~ {tag}，占 10%~25%。
- 点缀（{物象}）限定在 {accent_hex}，占 1%~5%，⛔不出现高饱和红/蓝/紫/荧光色。
- 整幅背景平均亮度 L∈{整幅L区间}；⛔禁止纯黑 #000000 与纯白 #FFFFFF 大块区域。
- 上方叠字区亮度 L∈{叠字区L区间} 且局部明暗波动 σ≤8%，保证后期叠{浅/深}色文字对比度≥4.5:1。

【强制·零字符（最重要）】
- 整幅画面零字符：不得出现任何汉字、英文字母、数字、标点、书法、印章、题字、书名、标签、logo、水印、二维码、伪汉字笔画。
- 书封面、陶盆、杯身、纸页表面必须完全空白，⛔禁止 AI 补小字、抬头、表格线、签名栏、乱码。
- ⛔禁止把提示词里的任何短语照排进画面。

【对抗约束·逐元素枚举变形风险（铁律-027①）】
- 人物风险：⛔不出现任何人物、人脸、手部、身体剪影或拟人化轮廓（避免剪影被性别化）。
- 主体风险：{物象专属禁例，逐条写死数量/状态/位置}。
- 器物风险：⛔器物不变形、不叠加同类、不加多余构件；⛔茶杯/陶杯不加把手指环，⛔书不多本堆叠，⛔小泥铲不变形为农具/武器。
- 构图风险：⛔主体不居中顶满，⛔叠字区不被物件遮挡，⛔主体不贴边、不被裁切。
- 光线风险：⛔不出现硬边光斑、镜头炫光条纹、过曝白块；只用柔和侧逆光/漫射光。

【风格】胶片摄影质感、浅景深、颗粒细腻、沉静克制、无过度摆拍、无插画感、无 3D 渲染感、无边框、无装饰花纹。
```

> 骨架可固定，**变量一天一换**。`scripts/agnes_jinju.py` 负责自动填槽并打印变量回执（便于核对是否真的换了）。

## 9. 出图后验收（铁律-027③，缺一不交付）

1. **字形自检**：`font_supports_text` 逐字通过，不得有豆腐块。
2. **像素体检**：文字落区 `L / σ / 对比度≥4.5:1`、落款区净底色对比度、成品尺寸 1080×1440、文件字节数打印。**落款色自适应**：底部渐隐完成后，按净底色亮度从 `sub / text / couplet` 三个同色系候选墨色中取对比度最高者，日期 / 引文 / 底图说明三行统一使用该墨色（仅作用于 Agnes 卡叠字，不改 `card_common.py` 配色真源）。**硬门禁**：任一对比度 <4.5:1 → 删除已生成的 PNG、`sys.exit(3)` 交上层降级，⛔禁止「告警但照常交付」。
3. **目视回读**：底图零文字、零人物、主体数量正确、构图未贴边（用图片查看工具回读，不以「已生成」替代「符合约束」）。若主体实际位置/器物细节与提示词有偏差（如 11-13 底图花苗偏左、茶杯多出把手），**如实记录偏差并收紧下一日的对抗约束，但本次不重复生图、不二次扣费**。
   - **2026-11-14 实测偏差**：提示词要求「远山与素石」严格位于下三分之一偏右，Agnes 实际把远山横贯画面中部、素石偏大偏中，而触发事件转成的「一双收起的旧布鞋」反而成了画面最显眼的主体（喧宾夺主）。体检数值全部达标（主金句 4.55:1、落款 13.47:1），但构图与提示词不符 → 已在 `scripts/agnes_jinju.py` 构图风险行补「触发细节只能作弱化环境陪衬，不得比金句物象更显眼、不得横贯画面中部」，自下一日生效；本次不重复生图、不二次扣费。
   - **2026-11-14 呈现层缺陷**：`generate_overview.py` 的 `sanitize_text` 只清洗中点字符，CJK 字体无 emoji 字形，带 emoji 的 `--mood-label` 会渲染成方框豆腐块。临时处置为调用时去掉 emoji（未改脚本、未动配色真源）；**脚本层根治待用户确认后再动**。
4. **落款压浅色 → 只做本地重绘**（加强底部渐隐至 `bg_bottom` + 落款色自适应），不二次调 Agnes；重绘后仍不达标 → 拒绝交付、走降级。
5. **产物**：`dushe_jinju_YYYY-MM-DD_agnes.png`，**不覆盖**同日 `dushe_jinju_YYYY-MM-DD.png`（本地 Pillow 版并存）。
6. **动态校验**：脚本落盘 `_agnes_vars_MMDD.json` 变量回执，与昨日回执比对并打印 `必变项 x/2` 与 `条件项 x/y`；必变项缺任一、条件项缺任一即告警。找不到回执（首次运行 / 11-13 及更早的旧格式文件）时回退纯文本三行比对。辅助打印「文本槽位变化 n/3」仅供人工核对，**不作判废依据**。
   - 反例基准（2026-11-13 模拟跑）：全同参数 → `必变项 0/2` 告警；只换金句 → `1/2` 且不再误判套模板；心情/标签/金句/事件全变 → `2/2 + 条件 2/2` 通过。
7. **降级出口**：`--gen-script` 缺失 / 凭据缺失 / Agnes 接口失败 / 体检不达标 → 一律退出码 3；⛔不得把不合格图留在交付目录。

## 10. 降级链（零配置仍然成立）

```
Agnes 可用（本机密钥已注册）→ 零文字底图 + 本地叠真字   ← 主渲染（每日默认）
```

- 每日只调一次 Agnes；返工走本地，不重复扣费。检测到通道不可用时应如实说明，不得谎称「已生成 Agnes 版」。
